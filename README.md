# Project documentation

Publishes Emu68 Hatcher at https://rootrootde.github.io/emu68hatcher/.

Run **Deploy documentation** to rebuild the documentation from the main branch of
**emu68-hatcher**. The workflow checks out the source from the same account as this
repository and publishes it under **emu68hatcher/**. No separate access token is needed.

The repository name and published documentation path are independent. Keep the
output directory unchanged when renaming the source repository.
